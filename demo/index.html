A high probability is a model score, not calibrated clinical confidence. The measured baseline's high accuracy hides poor performance on several minority classes. The curated examples here cannot estimate overall performance.

Trained-model inference is available in the repository's local FastAPI application. This public static demo does not run those models. The RR ablation needs earlier beat timing and is available in measured comparisons only. Beat locations are supplied; R-peak detection is not evaluated.
